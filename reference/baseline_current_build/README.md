# What the CURRENT build looks like (commit 6fa06ea, 26 Oct 2026)
Captured by the reviewer with headless Chromium (SwiftShader software GL, 720x910 or 800x520). Frame rate in these captures is not representative of a real GPU; the IMAGES are representative because shaders and geometry are the same.

- natatorium_spawn.png: `?map=natatorium&seed=12345`. A narrow channel of dark green marbled stripes between cream walls. Black void above the walls (no ceiling, no sky colour). The creature is only a magenta debug marker. Compare with reference frames f_005 to f_010.
- natatorium_monster_9m.png: creature teleported 9.5 m ahead with the H debug key. Floor tiles are huge bevelled blocks (about 0.4 to 0.5 m), the horizon is a white glow band over a black void, two dark boxes hide the creature.
- orientation_first_run.png: the first thing a new player sees after Descend and calibration: the 'Orientation' training pool with a ring of rotated stone blocks, grey-white water, a tethered creature 23 m away (a magenta label).
- main_menu_1440.png: the menu. The 3D hero scene is not visible, only text on black.
