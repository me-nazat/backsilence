# BackSilence reference pack (real footage)
Unzip this folder into the repository root so that it REPLACES `reference/video/notes.md` and fills `reference/video/frames/`.
Contents:
- video/frames/f_001..f_037.png: real frames from the owner's video (first three full 720x1280, the rest cropped to the 720x910 game region).
- video/notes.md: captions written by looking at the frames (the previous notes.md described frames that never existed).
- video/palette.json and video/measured_targets.json: measured colours and luminance statistics.
- audio/clip_01_full.wav and audio/notes.md.
- baseline_current_build/: screenshots of how the build looks today, for before and after comparison.
- compare_board.png: reference (left) against current build (right).
