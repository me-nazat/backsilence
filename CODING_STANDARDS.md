# BackSilence — Coding Standards

## TypeScript Configuration

- `strict: true` with all additional strictness flags enabled
- `noUncheckedIndexedAccess`: every indexed access is `T | undefined`
- `noImplicitOverride`: `override` keyword required on overridden methods
- `exactOptionalPropertyTypes`: optional properties cannot be assigned `undefined`
- **No `any`.** ESLint rule `@typescript-eslint/no-explicit-any: error`

## Module System

- ES modules only. No CommonJS `require()`.
- Named exports exclusively (no default exports except config files).
- Files must be ≤ 300 lines. Split by responsibility.

## Hot-Path Performance

- **No per-frame allocations.** Reuse `Vector3`, `Quaternion`, `Color` scratch objects.
- No closures or array literals created inside `update()` loops.
- Pre-allocate and pool where possible.

## Resource Management

- **Every system exposes `dispose()`.** No exceptions.
- Geometries, materials, textures, render targets, audio nodes, and event listeners must be released.
- Use `DisposableBag` from `src/engine/Disposal.ts` to track and release resources.
- Dispose in reverse order of creation.

## Determinism

- All procedural content uses the seeded PRNG (`mulberry32`) from `src/procedural/core/prng.ts`.
- **Never call `Math.random()` in generation code.**
- A given `(seed, mapId)` must produce byte-identical worlds on every client.

## Game Loop

- Fixed-timestep simulation at 60 Hz with render interpolation.
- Clamp `dt` to 0.1 s maximum.
- Pause when the tab is hidden.

## Decoupling

- Systems communicate through the typed `EventBus` and the typed `Store`.
- No system imports another system's internals.
- No circular dependencies.

## Documentation

- JSDoc on all public APIs.
- No magic numbers; constants live in `Config.ts` or the `WORLD` object.
- Every design decision recorded in `DECISIONS.md`.

## Error Handling

- Never swallow errors silently.
- Use `Result`-style returns or throw typed errors.
- Show user-facing failures through `Toasts`.

## Accessibility

- Focus-visible styles on all interactive elements.
- ARIA roles on menus and dialogs.
- `prefers-reduced-motion` respected (animations disabled/reduced).
- Scalable rem-based text.
- Full keyboard navigation of all menus.

## Asset Policy (Zero-Bloat)

- **No image, audio, video, font, 3D model, HDR, or texture files** anywhere in the project.
- Every texture generated by TypeScript + Canvas 2D + GLSL.
- Every sound synthesized with Web Audio API.
- Every model built from code using Three.js primitives.
- Inline SVG strings in code are fine. No `.svg` files.
- The only exception is the favicon as an inline `data:` URI.

## Git

- Commit after each milestone with a clear message.
- Never push (local development only until CI is configured).
