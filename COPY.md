## 7. Native-Review Localization Workflow

Antigravity auto-generates initial beta translations with `needsReview: true` for all non-English locales in `src/i18n/locales/*.json`. The UI displays a subtle `"Beta translation"` badge for unverified locales.

### Step-by-Step Review Protocol:
1. **Clone & Inspect:**
   - Locate the target locale file: `src/i18n/locales/<locale-code>.json` (e.g., `es.json`, `ja.json`, `ar.json`).
2. **Review Voice & Tonality:**
   - Ensure the tone matches BackSilence's quiet, dry, found-footage municipal atmosphere. Avoid cheerful, casual mobile-game phrases.
   - Maintain concise character counts: labels must fit within compact 44px buttons and OSD banners without truncation.
3. **Validate Placeholders & Formatting:**
   - Preserve all `{param}` formatting keys (e.g., `{count}`, `{time}`, `{score}`, `{player}`).
   - Verify that right-to-left languages (`ar`) retain left-to-right numerals for timers and ratings.
4. **Mark as Verified:**
   - Once all strings in the locale dictionary have been read and verified by a native speaker, update the header in `src/i18n/locales/<locale-code>.json`:
     ```json
     {
       "_meta": {
         "locale": "es",
         "needsReview": false,
         "reviewer": "@contributor",
         "verifiedAt": "2026-10-24"
       }
     }
     ```
5. **Run Verification:**
   - Run `npm run verify` to execute `scripts/i18n/check.mjs` asserting key parity and absence of untranslated placeholders.
